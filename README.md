## Featured Projects

### 🩺 Intelligent Clinical Decision Support System (CDSS)
Final-year thesis project — an end-to-end platform for automated prescription analysis and multi-disease risk prediction, supporting both handwritten and digital prescriptions.

- Handwritten/digital prescription processing via **OCR** (Google Cloud Vision) and **Clinical NER**
- Multi-disease risk prediction (diabetes, obesity, cardiovascular, liver) with confidence scoring, using **scikit-learn, XGBoost, LightGBM, TensorFlow**
- Five role-based portals (Admin, Receptionist, Doctor, Laboratory, Patient) secured with **JWT authentication** and RBAC
- **React + Tailwind + Framer Motion** frontend, **FastAPI + SQLAlchemy** backend, relational database

**Tech:** `React` `Tailwind CSS` `Framer Motion` `FastAPI` `Python` `SQLAlchemy` `JWT` `Scikit-learn` `XGBoost` `LightGBM` `TensorFlow` `OCR` `Clinical NER`

[![GitHub](https://img.shields.io/badge/Code-181717?style=flat-square&logo=github)](https://github.com/tasfiatasnim18/clinical-decision-support-system-handwritten-digital-prescription)

<sub>An earlier, smaller iteration of this project (digital prescriptions only) is archived at [`clinical-decision-support-system`](https://github.com/tasfiatasnim18/clinical-decision-support-system).</sub>

### 📰 Bangladesh News Sentiment Forecast
Scrapes monthly headlines from major Bangladeshi newspapers and predicts overall, economic, crime, and political sentiment, with topic-level word cloud visualizations.

- Automated **web scraping** pipeline (`requests`, `BeautifulSoup4`) across two newspaper sources
- NLP preprocessing and sentiment scoring with **NLTK**
- Topic-level sentiment breakdown (economy / crime / politics) plus word cloud visualization with `matplotlib`/`wordcloud`

**Tech:** `Python` `BeautifulSoup4` `NLTK` `Matplotlib` `WordCloud`
