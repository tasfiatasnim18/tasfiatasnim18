## Featured Projects

### 🩺 Intelligent Clinical Decision Support System (CDSS)
Final-year thesis project — an end-to-end platform for automated prescription analysis and multi-disease risk prediction, supporting both handwritten and digital prescriptions.

- Handwritten/digital prescription processing via **OCR** (Google Cloud Vision) and **Clinical NER**
- Multi-disease risk prediction (diabetes, obesity, cardiovascular, liver) with confidence scoring, using **scikit-learn, XGBoost, LightGBM, TensorFlow**
- Five role-based portals (Admin, Receptionist, Doctor, Laboratory, Patient) secured with **JWT authentication** and RBAC
- **React + Tailwind + Framer Motion** frontend, **FastAPI + SQLAlchemy** backend, relational database

**Tech:** `React` `Tailwind CSS` `Framer Motion` `FastAPI` `Python` `SQLAlchemy` `JWT` `Scikit-learn` `XGBoost` `LightGBM` `TensorFlow` `OCR` `Clinical NER`
